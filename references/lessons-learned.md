# 踩坑记录(完整版)

SKILL.md 正文里只放精简后的规则一句话;这里是每条规则背后"具体哪里错了、
为什么错、改成什么样"的完整记录,供需要时展开参考,也方便以后继续往里加。

## 代码层面

**Y坐标常量混用导致角色消失/叠位**
两格用同一个坐标变量(比如两格都写 `cy`)、或者复制粘贴时忘记把 `CY1` 改成
`CY2`,会导致角色渲染在错误位置,甚至跟另一个元素完全重叠而"看不见"。教训:
两个格子的中心常量必须用不同名字(`CY1`/`CY2`),写完渲染前搜一遍有没有
误用同名变量。

**Python f-string 里 `"\\n"` 不是真的换行**
多行文案写成 `"第一行\\n第二行"`(双反斜杠)在 Python 源码里是字面的反斜杠+n
两个字符,不会换行,渲染出来会看到字面的 `\n`。改用 `chr(10)` 拼接,或者用
真正带换行符的三引号字符串。

**str_replace 编辑整段函数时,容易把下一个函数的签名行一起删掉**
比如替换"函数体结尾"时,如果 `old_str` 的末尾恰好是另一个函数的 `def` 行,
稍不注意就会把这行也纳入替换范围一起删掉,导致下一个函数的函数体变成"孤儿
代码"(没有 `def` 包裹),整个文件 import 失败或者行为异常。这个 bug 在这个
项目里至少发生过两次(`cross_out` 函数被误删过两次)。教训:大段替换前先
`view` 精确确认 `old_str` 的边界,不要让替换范围延伸到下一个函数的签名行;
改完立刻 `python3 -c "import comic_lib"` 测试能不能正常导入,别等到渲染报错
才发现。

**重复代码是编辑事故的温床**
`worker_figure` 最早给 5 种站立类姿势(reach/sip/wave/point/stand)各自写了
一遍完全相同的躯干+腿部代码,只有手臂不同。这种重复不仅冗余,还意味着以后
改躯干比例要同时改5处、漏改一处就会造成姿势之间比例不一致。后来重构成
`_standing_torso_legs()` 共享函数,每个姿势只保留手臂那两行。这类"整段复制
再改一个参数"的写法,看到就应该考虑要不要提取共享函数。

## 视觉/审美层面

**把情绪具象化的道具直接挂在脸/身体上,容易变瘆人**
最初想把"眼皮跟挂了秤砣似的"这个说法直接画出来——真的在眼皮上挂两个小
哑铃。放大看细节还挺可爱,但缩小到正常尺寸,读者反馈是"像眼球脱出来挂着、
像伤口滴血,很吓人"。同一批还试过用一滴深色"哈喇子"表示流口水,也被反馈
说像伤口。教训:面部表情不要自己发明新符号去具象化一个感受,优先用读者已经
见过一千遍、确认安全的卡通惯例——困了用从鼻子冒出来的睡觉泡泡串、脸红晕、
汗滴、晕眩线。外物具象化(把感受画成一个道具)留给道具和场景层面用(鸟笼、
锅、胡萝卜钓竿这些不会引起生理不适感的对象),不要往脸和身体上招呼。

**"睡着了"和"困但醒着硬撑"画错会和文案对不上**
文案说的是"手指还在动/眼睛还盯着屏幕"这种"清醒但很累",却画了一个双眼
紧闭、鼻子冒睡觉泡泡的角色——画面在说"已经睡着",文字在说"还醒着硬撑",
两者矛盾。改法:清醒但疲惫要画**睁着的眼睛**(可以是重眼皮、黑眼圈、瞳孔
看向具体方向),已经睡着才用闭眼+睡觉泡泡。

**"躺床上"被画成裹成一团看不出四肢的茧/毛毛虫**
一开始为了"可爱"把整个身体简化成一个被子包裹的椭圆形茧,只露出一个头,
结果配上伸出去的手臂,读者反馈"看着像人被吊着,不像躺着"——因为身体没有
表现出平躺的骨架逻辑,四肢从一个不合逻辑的位置凭空冒出来。改法:平铺画出
枕头、被子轮廓、露出的四肢位置要符合平躺的人体结构,不要用一个简化的几何
形状代替整个身体。

**手臂画成一条圆滑长弧线,读起来像"被吊着"而不是"撑着"**
无论是"举着手机的手臂"还是"撑在枕头上的手肘",如果画成一条从肩到手的
平滑曲线(SVG 的 `Q` 二次贝塞尔曲线),视觉上会显得手臂像一根绳子或气球,
可以被任意拉长/弯曲,给人"悬空吊着"的感觉,而不是"有骨骼关节撑着某处"的
实感。改法:一律用两段直线在关节处转折(肩→肘→手,`stroke-linejoin="round"`
产生自然的转角),两段折线才有骨骼关节的实感。

**装饰性道具(挂画等)读不出是什么,还挡在文字预留区里**
在卧室场景背景里加了一幅"挂画"装饰(一个深色方框+浅色内框),本意是增加
生活气息,结果:①方框本身太抽象,读者看不出是挂画;②方框的位置刚好和
顶部标题文字重叠,标题被方框"腰斩"看起来像断开的两截。改法:装饰性道具
如果读不出是什么、或者挡在文字安全区,直接删掉——干净比"氛围感"更重要。

**只画了头,没画身体/只画了一只手**
最早的单图语录体系列图里,人物只有一颗悬浮的头,没有躯干和四肢;后来加了
身体,但某些姿势(比如"单手举手机")真的就只画了那一只手,另一只胳膊完全
没画,导致人物看起来像截肢。改法:检查清单里加一条硬性要求——人物必须是
完整身体(头+躯干+四肢),即使某个动作理论上只用得到一只手,另一只手/胳膊
也要以"自然搭着/垂着"之类的姿态画出来,不能凭空消失。

**同一份"语录合集"里,人物长得一模一样反而不像参考的爆款风格**
最初做了一套"打工人"角色,10张语录图全部复用同一张脸——后来对照参考的
爆款系列图才发现,人家的每张图角色都不一样(发型、体型、有没有戴眼镜都在
变),统一的是**画风**(线条粗细、配色、构造方式),不是**角色本身**。这一点
和模式A的猫主角刚好相反:模式A是连续剧情要让读者认出"这是同一只猫";
模式B是互相独立的语录卡,换人反而更真实,像"很多打工人的真实写照"而不是
"一个人的连环画"。`worker_figure`/`worker_face` 后来加了 `hair`/`mustache`/
`hair_color`/`shirt_color` 参数支持这一点。
