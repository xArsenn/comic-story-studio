# Metaphor library

Pick one world per series. Don't mix. Each entry gives the stock role-mapping so you can
go straight from "which article beat is this" to "which character/prop draws it."

## 相亲 / 婚恋 (matchmaking) — used for: a struggling asset/entity that needs new buyers

- 缺买家的资产/机构 → 相亲对象本人 (an anthropomorphized IOU/ledger character)
- 新买家/新资金来源 → 上门提亲的新人
- 监管方/规则制定者 → 婚姻登记处 / 媒人
- 资产必须满足的条件 → 彩礼清单 / 择偶条件
- 资金规模扩大 → 彩礼越办越大 / 随份子的人越来越多
- 收尾自嘲 → 主角发现自己也"随了份子"

Good for: bond markets, any "who will buy this" story, M&A explainers.

## 体检 / 看病 (medical checkup) — used for: diagnosing a system's health, risk build-up

- 系统/公司/经济体 → 病人
- 指标恶化 → 体检报告异常项
- 早期预警信号 → 轻微症状被忽视
- 监管介入 → 医生开处方/住院
- 风险蔓延 → 并发症
- 结局(好/坏) → 康复 or 转为慢性病需长期管理

Good for: financial-stability pieces, "is X in a bubble" pieces, risk-buildup narratives.

## 升级打怪 (RPG leveling) — used for: a strategy/plan executed in stages

- 主角 → 玩家角色
- 目标 → 通关/下一关
- 资源/资本 → 金币、装备
- 竞争对手 → 怪物/Boss
- 试错/小成本验证 → 刷小怪攒经验
- 决定性一战 → Boss战

Good for: startup/business-strategy pieces, career pieces, "how to approach X" explainers.

## 期末考试 (exam) — used for: a deadline-driven pass/fail evaluation

- 被评估的对象 → 考生
- 评估标准 → 考纲/评分标准
- 数据/财报 → 卷面成绩
- 监管/评级机构 → 阅卷老师
- 补救措施 → 补考/加分项
- 结果 → 及格线上下

Good for: earnings-season pieces, credit-rating pieces, compliance-deadline pieces.

## 招聘面试 (job interview) — used for: selecting among competing options

- 决策方 → 招聘方/HR
- 候选方案们 → 应聘者
- 筛选标准 → JD/岗位要求
- 淘汰的方案 → 面试被刷的候选人
- 最终胜出方案 → 拿到offer的人
- 意外结局 → 空降的"内推"打破常规筛选

Good for: "which asset class wins" pieces, policy-option comparisons, vendor/tool
comparisons.

---

## How to extend this file

When a new article needs a metaphor none of the above fit well, design it once, get it
signed off, then add it here with the same role-mapping shape — so next time it's a lookup,
not a fresh design.
